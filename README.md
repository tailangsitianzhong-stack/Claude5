# Starward — 宇宙船操縦プロトタイプ (Godot 4)

近未来的な宇宙船で恒星系を飛び回る、操縦だけに絞ったプロトタイプです。
惑星への着陸はなく、天体に近づきすぎると跳ね返されます。

## 起動方法
1. [Godot 4.3 以降](https://godotengine.org/download)（標準版、.NET不要）をインストール
2. Godot のプロジェクトマネージャーで「インポート」→ このフォルダの `project.godot` を選択
3. F5 で実行

アセットは使っておらず、機体・惑星・星空はすべてコードとシェーダーで生成しています。

## 操作
| 入力 | 動作 |
|---|---|
| マウス | 機首の向き（仮想ジョイスティック：中心からのずれ量で旋回） |
| W / S | スロットル増減（離しても維持） / X: スロットル0 / ホイール: 微調整 |
| A / D | ロール |
| Q / E | 左右平行移動、Space / Ctrl: 上下平行移動 |
| 矢印キー | ピッチ / ヨー |
| Shift | ブースト（ゲージ消費） |
| Tab | ワープ（2秒充填、天体付近では不可・接近で自動減速→離脱） |
| T | ターゲット切替、Y 長押し: ターゲットへ自動旋回 |
| Z | フライトアシスト ON/OFF（OFFで慣性飛行） |
| C | カメラ切替（追従 / 遠景 / コックピット） |
| V / 中クリック | 照準センタリング、M: マウス方式切替（仮想 / ダイレクト）、I: 上下反転 |
| Backspace | スタート地点に戻る（ゲートコースもリセット） |
| H | 操作説明の表示切替、Esc: マウス解放 |

ゲームパッドも一部対応（左スティック: 旋回、トリガー: スロットル、LB/RB: ロール、A: ブースト、Y: ワープ）。

## 星系
太陽ソル / ヴァルカン（溶岩）/ アクア（海洋）/ テラノヴァ（地球型・衛星ルナリス）/ 小惑星帯 / ジュピタス（環付きガス惑星）/ グレイシア（氷）。
スタート地点の前方に 10 個のリングゲートのタイムアタックコース、右前方に練習用の小惑星群があります。

## 調整ポイント
| ファイル | 内容 |
|---|---|
| `scripts/ship.gd` | 飛行特性。冒頭の `@export` 変数（最高速度、旋回速度、加速度、ワープ速度、マウス感度など） |
| `scripts/chase_camera.gd` | カメラ位置 `OFFSETS`、追従の滑らかさ `SMOOTH`、FOV |
| `scripts/main.gd` | 惑星データ `PLANETS` / `MOONS`、小惑星数、ゲート数・サイズ、キー割り当て `_setup_input()` |
| `scripts/ship_model.gd` | 機体の形状・色、噴射炎 |
| `scripts/hud.gd` | HUD 表示 |
| `shaders/` | 星空・惑星・大気・太陽などの見た目 |

距離の単位は 1 = 1m 想定です（通常最高速度 300m/s、ワープ最大 15km/s）。
